# Retrospective

**Retrospective documentation, written on 20 October 2026.** This is a later record for a 2023 solo college project, not backdated build documentation.

## What worked
- Combining sensors, motors, servo, and pump created a tangible embedded-systems project.
- The project required integration across mechanical, electrical, and firmware decisions rather than a single isolated sensor.

## What should be improved
- Preserve the original sketch, wiring, photos, and test results at build time.
- Measure sensor range/false positives, obstacle distance accuracy, response time, and pump/nozzle behaviour.
- Add safe test evidence and a reproducible pin map.

## Lesson
Hardware portfolios become far more credible when they show the build artefacts, safety process, and measured test evidence—not only the final concept.
