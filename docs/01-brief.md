# Project brief

**Project:** Fire-Fighting Robot Car  
**Year:** 2023, third semester  
**Delivery:** Solo college hardware project

## Brief
Build a small Arduino-based wheeled robot to demonstrate flame sensing, obstacle avoidance, temperature checking, movement, and water-nozzle aiming in a controlled environment.

## Users
College reviewers and embedded-systems learners.

## Success criteria
The original build combined the listed sensors/actuators into one prototype. Because recorded measurements are unavailable, this repository does not claim a detection range, accuracy, extinguishing time, or safety certification.

## Constraints
The exact board model, pin assignment, component ratings, code, photos, and test measurements still need to be verified and uploaded from the original build.
