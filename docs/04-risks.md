# Risks and safety notes

| Risk | Mitigation |
| --- | --- |
| Water near electronics | Use low-voltage isolated supply, keep tubing secure, test pump separately, and power down before wiring changes. |
| Moving wheels/servo/pump | Keep hands, loose clothing, and valuables clear; raise wheels for bench tests when appropriate. |
| Heat/flame testing | Do not use uncontrolled fires. Use only safe instructor-approved demonstrations. The robot is not emergency equipment. |
| Battery/power fault | Use appropriate rated components/fuse practices, inspect wiring, and never leave the robot unattended while powered. |
| False sensor readings | Test one sensor at a time and document environmental conditions; provide a manual stop. |
| Unknown original pin map | Do not power the recreated build until exact physical wiring is confirmed against the original sketch/build. |
